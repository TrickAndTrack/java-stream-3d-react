# Java Stream API — 3D StreamVerse

A Vite + React + TypeScript app using **Three.js / WebGL** for a real 3D pipeline. Drag the scene to rotate the camera group. No backend is required.

## Requirements
- Node.js 20+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL Vite prints (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## What is included
- Real Three.js 3D scene: perspective camera, 3D meshes, metallic materials, lighting, fog, grid floor and animated data tokens.
- Drag to rotate the 3D scene.
- React controls for operation selection, custom input, filter condition, limit/skip N, restart, step, and play/pause.
- Function library retaining the six original categories and all original catalog entries (creation, intermediate, terminal, primitive streams, collectors and characteristics).
- Result output and a Java reference panel.

## Accuracy note
This is an interactive learning visualizer, not a JVM executing Java source. The UI calculates illustrative results in TypeScript for the supported operations; some source/characteristic entries are explanatory examples rather than full Java runtime simulations. Validate Java snippets against your target JDK before using them in production.
